# Бенто Калька AR

AR-калька для рисования на бенто-тортах в Meta Quest 3. Работает как веб-страница (WebXR):
ничего не нужно ставить, достаточно открыть ссылку в браузере шлема.

**Открыть:** https://qwastedz-source.github.io/bento-ar/ · **Пошаговый гайд:** [GUIDE.md](GUIDE.md)

Ветки: `main` публикуется на сайт, `dev` для продолжения разработки.

## Что умеет

- **Фото с телефона на шлем (iPhone/Android):** на шлеме QR-код и постоянный код из 6 букв. На телефоне `send.html` позволяет выбрать фото, и оно появляется на шлеме за секунду, даже посреди AR. Передача идёт напрямую по WebRTC (PeerJS), через сервер проходит только «рукопожатие».
- **Чёткие линии в шлеме:** контур рисуется шейдером из поля расстояний (точный EDT), поэтому край всегда в 1 пиксель экрана, без мыла вблизи и без пропадания издалека. Тонкая тёмная обводка для контраста на креме. Рендер в родном разрешении дисплея, 90 Гц. Толщина и цвет меняются мгновенно.
- **Недавние картинки:** последние 8 хранятся в шлеме (IndexedDB).
- **Меню прямо в AR:** сменить картинку из недавних, настроить трафарет (режим, толщина, детализация, цвет), откалибровать заново или выйти с подтверждением. Положение не сбивается.
- **Устанавливается как приложение (PWA):** иконка в библиотеке Quest, работает и без интернета после первого запуска (кроме пересылки с телефона).

- **Подготовка картинки:** любое фото или клипарт превращается в контур (детектор краёв с очисткой от мусора), в контур поверх фото, в тёмные пятна или остаётся фото. Толщина линий задаётся в **миллиметрах на торте**.
- **Кадрирование под торт:** круглый или квадратный, диаметр 6–20 см. Картинку двигаешь и масштабируешь прямо на превью.
- **Калибровка по реальному торту:**
  - «Край · 3 точки»: виртуальная игла на контроллере (касаться крема не надо) или щипок руками. Центр, диаметр и высота торта считаются сами.
  - Для квадратного торта: два ближних угла.
  - «Центр · 1 точка»: быстрый вариант.
- **Точная подгонка:** шаг 1 или 5 мм, поворот на 1°, высота, размер; стики; перетаскивание через grip (высота при этом не сбивается).
- **Максимальная заморозка:**
  - после ЗАМОРОЗИТЬ любые сдвиги отключены, работают только прозрачность, скрыть/показать и контур/фото;
  - картинка садится на **системный якорь Quest (XR Anchor)**: шлем сам корректирует его по карте комнаты, поэтому дрейфа меньше;
  - якорь **сохраняется между заходами** (persistent anchor): вышел из AR, сменил картинку, зашёл обратно, и она на том же месте;
  - разморозка только **удержанием 1.5 с**, случайно не нажмёшь;
  - пересброс центра (долгое нажатие кнопки Meta) компенсируется.
- **Руки поверх картинки:** пальцы перекрывают трафарет, поэтому видно, где кончик насадки.
- Обод, сетка и метка «верх» помогают проверить совмещение.

## Управление в шлеме

| Что | Контроллер | Руки |
|---|---|---|
| Нажать кнопку панели | курок по лучу | щипок по лучу |
| Точка калибровки | кончик иглы + курок | щипок над точкой |
| Сдвиг | правый стик | кнопки ← ↑ ↓ → |
| Поворот / высота | левый стик (влево-вправо / вперёд-назад) | кнопки |
| Перетащить | держать grip | — |
| Контур ↔ фото | A | кнопка |
| Скрыть / показать | B | кнопка |
| Панель | X | ладонь вверх ~1 с |
| Заморозить / разморозить | Y / держать Y 1.5 с | кнопка / держать 1.5 с |

## Как открыть на Quest 3

WebXR работает только по **https** (или на `localhost`).

### Вариант 1. GitHub Pages (бесплатно, постоянная ссылка)
1. Создай публичный репозиторий и загрузи туда содержимое этой папки.
2. Settings → Pages → Branch: `main` / root → Save.
3. Через минуту сайт будет на `https://<логин>.github.io/<репо>/`. Открой эту ссылку в браузере Quest и добавь её в закладки.

### Вариант 2. Локально через USB (для разработки)
Нужен режим разработчика на Quest и `adb`.
```
node serve.mjs
adb reverse tcp:8765 tcp:8765
```
В браузере Quest открой `http://localhost:8765`.

## Советы, чтобы не плыло
- Яркий ровный свет, а на столе и вокруг побольше деталей: трекинг держится за текстуры. Однотонный белый стол хуже.
- Торт не двигай. Если стоит на поворотном столике, зафиксируй его. Повернул торт: разморозь и поверни картинку.
- Калибруй с того места, откуда будешь рисовать, и смотри примерно сверху.
- Не закрывай камеры шлема рукавом или волосами.
- Если картинка сместилась на миллиметр-два: разморозь, поправь шагом 1 мм и заморозь снова.

## Тесты
```
npm test
```
42 теста на Node без зависимостей: геометрия калибровки (круг по 3 точкам, квадрат по углам, направление картинки),
обработка картинки (линии, толщина в мм, удаление мусора, маска, пятна, фото), протокол пересылки, раскладку панели, настройки, офлайн-кэш и манифест.
Они же запускаются на GitHub при каждом push (`.github/workflows/test.yml`).

## Файлы
- `index.html`, `main.js`: страница подготовки (превью, вкладки, недавние, приём с телефона).
- `send.html`, `send.js`: страница для телефона.
- `styles.css`: общий дизайн (светлая и тёмная тема).
- `imageproc.js`: обработка картинки (контур, пятна, маска торта).
- `calib.js`: геометрия калибровки.
- `transfer.js`: коды и пересылка по WebRTC.
- `store.js`: недавние картинки (IndexedDB).
- `xr.js`: AR-режим (панель и меню, калибровка, якоря, руки, замена картинки на лету).
  Для разработки: `previewPanel('menu')` рисует панель на обычной странице.
- `layout.js`: раскладка кнопок панели.
- `sw.js`, `manifest.webmanifest`, `icons/`: установка как приложение и офлайн.
  Иконки рисуются скриптом `node scripts/make-icons.mjs`.
- `serve.mjs`: локальный сервер для теста.
- `tests/`: автотесты.
